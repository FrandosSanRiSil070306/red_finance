
# Red Finance

Sistema de controle financeiro pessoal desenvolvido como projeto avaliativo da disciplina de Ciência da Computação.

## Objetivo

O Red Finance tem como objetivo permitir que o usuário organize suas finanças pessoais, registrando receitas e despesas e acompanhando seu saldo.

## Funcionalidades

- Cadastro de receitas e despesas.
- Descrição, valor, categoria e data das transações.
- Visualização do total de receitas, despesas e saldo.
- Exclusão de transações.
- Filtro por categoria e mês.
- Gráfico de despesas por categoria.
- Armazenamento dos dados no navegador utilizando localStorage.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Chart.js

Os dados são armazenados localmente no navegador por meio do localStorage. O projeto não utiliza banco de dados on-line.
